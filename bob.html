Integrating Real IBM Bob / watsonx Assistant

To connect this website to a live IBM watsonx Assistant endpoint, replace the demo knowledge base with a real API call.

Step 1: Create a watsonx Assistant instance

  1. Log in to IBM Cloud
  2. Create a watsonx Assistant service (Lite tier is free)
  3. Build your assistant with food-waste intents and entities
  4. Note your Integration ID and Region URL
  5. Enable the Web Chat integration under Environments

Step 2: Embed the Web Chat widget

Replace the custom chat widget in js/main.js with the auto-generated IBM Web Chat snippet:

// In your HTML <head> or before </body>: window.watsonAssistantChatOptions = { integrationID: "YOUR_INTEGRATION_ID", region: "au-syd", // or us-south, eu-de, etc. serviceInstanceID: "YOUR_INSTANCE_ID", onLoad: async (instance) => { await instance.render(); } }; setTimeout(() => { const t = document.createElement('script'); t.src = "https://web-chat.global.assistant.watson.appdomain.cloud/versions/latest/WatsonAssistantChatEntry.js"; document.head.appendChild(t); }, 0);

Step 3: REST API for custom integration

For full control (custom UI, server-side logic), use the watsonx Assistant REST API:

// POST to create a session POST /v2/assistants/{assistant_id}/sessions Authorization: Basic base64(apikey) // POST a message POST /v2/assistants/{id}/sessions/{sid}/message Content-Type: application/json { "input": { "message_type": "text", "text": "What is food waste?" } } // Response includes: { "output": { "generic": [{ "response_type": "text", "text": "Food waste occurs when..." }] } }
